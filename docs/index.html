How it works

Write it down once.
Click it forever.

No task runner to learn. A JSON file in the repo root is the whole contract — commit it and the whole team gets the same buttons.

Features

Small buttons, serious plumbing

Everything you used to keep in a README of “how to run this” — and the deploy script you never wanted to write.

Server Uploads

FTP, FTPS and SFTP targets in server-uploads.local.json. Files, folders, globs and excludes; a connection pool; mirror mode that removes stale remote files; skipUnchanged for content-hashed builds. Cards show exactly which files changed since the last upload — and “Upload only modified” sends just those.

Quick Upload from Spec

One line to put a file on the server

Not every file belongs to a tracked upload. Paste a spec into Commands Extension: Quick Upload from Spec — an agent can write it for you — and everything for one server goes over a single connection.

  • local => server:/dir uploads a file or a whole folder, keeping its structure.
  • server:/path => local pulls from the server instead.
  • del server:/path removes a file or folder — after a modal that lists exactly what was found.
  • Pairs separated by ; or newlines, a live preview grouped by server, # comments ignored.

For agents

Plain JSON that an agent can write

Coding agents add a command, a combined operation or an upload spec as text — you just click the button. The file watcher picks up every change instantly.

{
  "commands": [
    { "name": "▶ Start (full)", "command": "./start.sh", "type": "terminal", "group": "App", "stop": "■ Stop" },
    { "name": "■ Stop",         "command": "./stop.sh",  "type": "terminal", "group": "App", "hidden": true },
    { "name": "Seed DB",        "command": "seed.js",    "type": "node",     "group": "Dev", "cwd": "./server" },
    { "name": "Deploy",         "command": "./scripts/deploy.ps1", "type": "pwsh", "group": "Deploy" }
  ]
}
{
  "combined": [
    {
      "name": "Install & Reload",
      "stopOnError": true,
      "steps": [
        { "type": "command",    "name": "Install local" },
        { "type": "upload",     "key": "Deploy:Theme → prod" },
        { "type": "vscode-cmd", "commandId": "workbench.action.reloadWindow", "enabled": true }
      ]
    }
  ]
}
{
  "servers": [
    { "name": "main", "protocol": "sftp", "host": "example.com", "user": "deploy" }
  ],
